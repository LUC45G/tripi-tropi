# Triage Labels

Use these strings in each local issue's `Status:` line.

| Canonical role | Tracker status | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue |
| needs-info | needs-info | Waiting on reporter for more information |
| ready-for-agent | ready-for-agent | Fully specified, ready for an autonomous agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

When a skill mentions a triage role, use its tracker status.
Edit the Tracker status column to change this repo's vocabulary.
